# Student Academic Performance & Learning Risk Analysis Using Machine Learning

## Project Overview

This project focuses on analysing student academic performance and identifying learning-risk patterns using fundamental data analytics and machine learning techniques.

The project uses a structured dataset of **200 students** containing academic, behavioural, and demographic attributes such as study habits, attendance, assessment performance, sleep patterns, and internet usage.

The objective is to explore relationships between these factors and students' academic learning risk through a systematic data science workflow.

## Key Components

- **Data Cleaning & Preparation:** Inspecting, cleaning, and preparing the dataset for analysis.
- **Exploratory Data Analysis (EDA):** Analysing data distributions, patterns, and relationships using statistical measures and visualizations.
- **K-Means Clustering:** Applying unsupervised learning to group students based on similarities in their academic and behavioural characteristics.
- **Decision Tree Classification:** Applying supervised learning to understand and classify student learning-risk categories.
- **Mathematical Analysis:** Understanding distance calculations, centroid updates, Gini Impurity, Entropy, and Information Gain.
